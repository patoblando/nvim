# Mi config de Neovim

Basada principalmente en [esta config](https://github.com/BreadOnPenguins/nvim) de [BreadOnPenguins](https://www.youtube.com/@BreadOnPenguins).
Igual uso otro plugin manager, pero le robé varios plugins y algunos keymaps que tenían sentido para mí :).


# Instalar (¿Por qué querrías instalarlo?)

Copia todo en `~/.config/nvim` y abrí NeoVim. Si tenés Windows, primero
desinstalalo, instalá cualquier distribución de linux y después copiá todo en 
`~/.config/nvim`.
